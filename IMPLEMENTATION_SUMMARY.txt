API ENDPOINT (server/routes/consultations.ts)
--------------------------------------------------------------------------------

NEW ENDPOINT: POST /api/consultations/:appointmentId/notes

Request Body:
  {
    "notes": "Patient consultation notes...",
    "diagnosis": "Patient diagnosis",
    "treatmentPlan": "Treatment plan details"
  }
  * All fields optional, at least one required

Response (200 OK):
  {
    "success": true,
    "message": "Consultation notes saved successfully",
    "data": {
      "appointmentId": "appt_123",
      "consultationId": "vc_456",
      "notes": "...",
      "diagnosis": "...",
      "treatmentPlan": "...",
      "updatedAt": "2025-10-26T14:30:00.000Z"
    }
  }

Error Responses:
  - 400: Missing required fields
  - 404: Consultation not found
  - 500: Internal server error

Features:
  ✓ Simple field validation
  ✓ TypeScript type safety
  ✓ Proper error handling
  ✓ Optional authentication support (commented out)
  ✓ Updates existing consultation records
